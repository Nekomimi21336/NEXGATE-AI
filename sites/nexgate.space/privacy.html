プライバシーポリシー

最終更新日：2026年5月25日

NEXGATE AI（以下「当社」）は、AI 補助ツール「NEXGATE AI」（以下「本サービス」）におけるユーザーの個人情報および関連情報の保護を重要視しています。本プライバシーポリシーは、当社が収集する情報、その利用目的、管理方法について定めるものです。

1. 収集する情報

当社は、本サービスの提供にあたり、以下の情報を収集する場合があります。

  • アカウント情報（ユーザー名、メールアドレス、パスワードのハッシュ等）
  • 利用情報（ログイン日時、利用プラン、トークン使用量、機能利用履歴、IP アドレス、ブラウザ種別、端末情報等）
  • 会話・入力情報（チャット内容、プロンプト、検索クエリ等）
  • アップロードファイル（PDF、画像、テキスト等）および OCR 処理結果
  • 決済情報（PayPal 取引 ID、プラン、請求履歴等。クレジットカード番号等の詳細は決済代行業者が管理し、当社は保持しません）
  • お問い合わせ内容（Discord 等を通じた連絡内容）

2. 利用目的

収集した情報は、以下の目的で利用します。

  • 本サービスの提供、認証、セキュリティ確保
  • AI モデルへの入力処理、Web 検索連携、ファイル解析、応答生成
  • 利用量管理、課金、プラン変更、サポート対応
  • サービス品質の改善、障害対応、不正利用の防止
  • 法令に基づく対応、権利侵害申告への対応
  • 重要な変更・メンテナンス等の通知

3. AI 処理に関する注意

ユーザーが入力した内容は、本サービスの提供に必要な範囲で、当社が契約する AI モデル API および関連インフラに送信・処理されます。ファイル内容は会話の処理に使用し、当社はアカウントごとにデータを分離して管理します。生成物の正確性は保証されません。詳細は利用規約第7条をご確認ください。

4. 第三者提供

当社は、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合
  • サービス提供に必要な業務委託（ホスティング、決済、AI API 等）を行う場合（委託先に対し適切な監督を行います）

5. 外部サービス

本サービスは、以下の外部サービスと連携する場合があります。各サービスのプライバシーポリシーもあわせてご確認ください。

  • AI モデル API 提供者（推論処理のため入力データが送信されます）
  • Web 検索 API（検索機能利用時）
  • PayPal（決済処理）
  • ホスティング・インフラ提供者

6. 保存期間

当社は、利用目的の達成に必要な期間、情報を保存します。会話履歴は、ユーザーが削除するまで、またはアカウント削除後、当社所定の期間内に削除します。法令上保存が必要な情報は、定められた期間保存します。

7. 安全管理

当社は、個人情報への不正アクセス、漏えい、改ざん、滅失等を防止するため、アクセス制御、通信の暗号化（HTTPS）、アカウント分離等の安全管理措置を講じます。完全な安全を保証するものではありませんが、継続的に改善に努めます。

8. Cookie 等

本サービスおよび nexgate.space では、認証状態の維持、セキュリティ、利用状況の把握のため Cookie および類似技術を使用する場合があります。ブラウザ設定により Cookie を無効化できますが、一部機能が利用できなくなる場合があります。

9. ユーザーの権利

ユーザーは、当社が保有する自己の個人情報について、開示、訂正、追加、削除、利用停止等を求めることができます。管理画面から変更できる項目はそちらをご利用ください。その他の請求は、Discord サーバーよりご連絡ください。本人確認のうえ、合理的な期間内に対応します。

10. 未成年者

本サービスは、原則として18歳以上の方、または法定代理人の同意を得た未成年者を対象とします。16歳未満の方から故意に個人情報を収集しないよう努めます。

11. ポリシーの変更

当社は、法令の変更やサービス内容の変更に伴い、本ポリシーを改定する場合があります。重要な変更は、本サービス上または nexgate.space で告知します。

12. お問い合わせ

個人情報の取扱いに関するお問い合わせは、Discord サーバーよりご連絡ください。
